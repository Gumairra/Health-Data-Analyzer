Parallel Health Data Analyzer

IFB206 - Parallel Computing Project

Project Overview

Parallel Health Data Analyzer merupakan aplikasi analisis data kesehatan yang menerapkan konsep komputasi paralel menggunakan Python Multiprocessing. Sistem memproses dataset pasien dengan membagi data ke beberapa process yang berjalan secara bersamaan.

Pendekatan ini memungkinkan proses analisis dilakukan lebih cepat dibandingkan pemrosesan secara sekuensial.

Parallel Computing Concepts

  • Data Parallelism : Dataset dibagi menjadi beberapa bagian yang diproses secara paralel.
  • Multiprocessing : Menggunakan beberapa process untuk mempercepat komputasi.
  • Workload Distribution : Beban kerja dibagi secara merata ke seluruh process.
  • Concurrent Execution : Semua process berjalan bersamaan untuk meningkatkan performa.

Dataset Information

Dataset berisi 1000 data pasien yang digunakan untuk simulasi analisis kesehatan.

  • Age : Usia pasien
  • BMI : Body Mass Index
  • Diabetes : Status diabetes pasien
  • Hypertension : Status hipertensi pasien

Output Explanation

  • Total Patients : Jumlah data pasien yang dianalisis.
  • Average Age : Rata-rata usia seluruh pasien.
  • Average BMI : Rata-rata indeks massa tubuh pasien.
  • Diabetes Patients : Jumlah pasien yang memiliki diabetes.
  • Hypertension Cases : Jumlah pasien yang mengalami hipertensi.
  • Execution Time : Waktu yang dibutuhkan sistem untuk menyelesaikan analisis.

Conclusion

Implementasi Python Multiprocessing berhasil menerapkan konsep komputasi paralel melalui pembagian dataset menjadi beberapa bagian yang diproses secara bersamaan.

Pendekatan Data Parallelism memungkinkan pemanfaatan sumber daya CPU secara lebih optimal sehingga proses analisis menjadi lebih efisien.
